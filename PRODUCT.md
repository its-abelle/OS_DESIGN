# Department of Files

## Register

product

## Platform

web

## Users

Students demonstrating a university practical and the lecturer assessing it.

## Product Purpose

A small working demonstration of registration, authentication, PDF storage and
retrieval using Docker, Nginx, Apache, Express, PostgreSQL and S3-compatible MinIO.
Users should be able to explain where account/file records and PDF bytes live.

## Brand Personality

Simple, humorous, deliberately bureaucratic. The user requested deep colours,
distinctive typography, square icons and humorous animations.

## Anti-references

Generic AI colour palettes, generic typography and an oversized SaaS presentation.

## Design Principles

Keep the task small. Make storage and retrieval observable. Let humour explain
state without obscuring errors. Preserve the existing Docker architecture.

## Accessibility & Inclusion

Implementation defaults include labelled forms, keyboard access, readable contrast,
responsive layout, clear error messages and reduced-motion support.
