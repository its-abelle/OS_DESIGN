    FOR THE LECTURER: FOLLOW A FILEUnder the hood +

    Classroom setup: five containers. One very well-travelled PDF. Here’s what each one actually does.

    1. 01
      Nginx

      The front desk. Receives browser requests on port 8080 and directs traffic.

    2. 02
      Apache

      Serves this HTML, CSS and JavaScript. Yes, both web servers have jobs.

    3. 03
      Express

      Checks sessions and ownership, validates PDFs, and handles API requests.

    4. 04
      PostgreSQL

      Keeps users, sessions and file records: name, size, owner, key and timestamp.

    5. 05
      MinIO

      Keeps the PDF bytes. Sends them back using a short-lived signed URL.

    Docker Compose brings the office together. Named volumes keep PostgreSQL and MinIO data across container restarts. Uploads go Browser → Nginx → Express → PostgreSQL + MinIO; downloads go directly from MinIO using the authorised link. The Vercel version combines Nginx, Apache and Express in one container and connects to hosted PostgreSQL and object storage.
