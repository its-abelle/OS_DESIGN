# COSC 428 — Group Practical Assignment

## Virtualisation, Containerisation and Web Application Deployment

Transcribed from the lecturer's brief supplied by the group.

### 1. Assignment Overview

Working in groups, set up a virtualised development environment using Virtual
Machines (VMs), Docker and an Ubuntu distribution. Configure the environment and
develop a simple web application using PHP and MySQL.

### 2. Assignment Tasks

#### Task 1: Set Up the Development Environment

- Install and configure Virtual Machines (VMs).
- Install and set up Docker.
- Install an Ubuntu distribution of your choice.
- Choose and configure a suitable interface for accessing the environment.

#### Task 2: Configure the Web Server Environment

- Log in to the configured environment.
- Explore and configure Nginx.
- Set up Apache as the web server within the backend container environment.

#### Task 3: Develop a Simple Web Application

- Use PHP to develop a simple Graphical User Interface (GUI).
- Create a functional interface that allows users to interact with the application.

#### Task 4: Database Integration

- Install and configure MySQL as the database management system.
- Create a database for the application.
- Link the PHP application to the MySQL database.
- Demonstrate communication between the application and the database.

### 3. Expected Deliverables

1. A functional virtualised environment.
2. A configured Docker environment running on Ubuntu.
3. A working web server configuration.
4. A simple PHP-based graphical user interface.
5. A MySQL database successfully connected to the PHP application.
6. All environments must be linked.
7. A written report documenting the setup process, configurations, implementation and results.

### 4. Submission

- Mode: Group assignment.
- Submission: Written report and practical demonstration.
- Deadline: 26th. No month/year was supplied in this text.

### 5. Conclusion

The assignment aims to provide practical experience in virtualisation,
containerisation, web server configuration, PHP application development and
database integration.
